## Why they are kept

A threshold with no reasoning behind it is a magic number, and a magic number cannot be argued
with — only changed. These documents record which thresholds come from Google (very few: the
750-character description cap, the three-result local pack, the six-month post archive), which
come from published industry study, and which are **our operating policy**.

That distinction is load-bearing. Every finding's `limitation` says which kind it rests on,
and the category documents repeat it per check. When someone asks "why 60% reply rate and not
50%", the answer is in here — and if the answer is "it is policy", that is said plainly rather
than dressed up as a rule.
